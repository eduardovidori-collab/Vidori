Pacote Base

15 moedas

Dois jogadores diferentes que passaram pelo SPFC. O sorteio considera o OVR e dá uma ajuda para completar sua coleção.

Raridades e probabilidades

Chances fixas por carta. Cada pacote contém dois jogadores diferentes. Dentro de cada raridade, jogadores com OVR maior são mais difíceis de conseguir.

Enquanto faltarem cartas de uma raridade, quem já saiu perde 1% da própria chance base (ex.: 50% para 49,5%; 1% para 0,99%), uma única vez. Novas cópias não acumulam a redução. A diferença favorece apenas jogadores que faltam nessa mesma raridade.

O ajuste mantém o peso total de cada raridade: uma comum repetida não aumenta a chance das raridades mais altas. Ao completar uma raridade, suas cartas voltam às chances base por OVR.
