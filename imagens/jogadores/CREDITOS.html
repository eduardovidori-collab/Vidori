Fotografias das Lendas

Os arquivos são reproduzidos a partir do Wikimedia Commons sob as licenças indicadas. Fotografias e créditos ficam disponíveis offline. São mantidas as licenças de cada imagem.

Os retratos receberam recorte para rosto e ombros, remoção de fundo e tratamento assistidos por IA. Foram compostos em uma imagem com transparência para as cartas. Não são imagens oficiais do FIFA/EA FC. As fontes fotográficas estão abaixo; Rogério Ceni usa a miniatura de 500 pixels do Commons e a fonte de Kaká já foi recortada por Tales.ebner. O conjunto de retratos adaptados é disponibilizado sob CC BY-SA 4.0, com os créditos das fontes preservados. Ver os cinco retratos com fundo transparente.
